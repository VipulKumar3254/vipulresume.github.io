## Brand & Style

This design system expresses high-end digital product craft, architectural precision, and uncompromising technical authority for a senior mobile systems engineer. The design aesthetic balances the discipline of high-fashion print editorial with the rigorous exactitude of modern compiler diagnostics and native runtime architecture. 

The emotional signature is cool, deliberate, and undeniably confident. It rejects generic developer portfolio tropes—such as over-saturated terminal greens, ambient neon glows, or hyperactive particle backgrounds—in favor of structural hierarchy, generous white space, bespoke asymmetric grid distributions, and tactical bursts of controlled kinetic energy. 

Key attributes:
- **Architectural Precision:** Every boundary is reinforced with razor-thin structural hairpins and strict mathematical ratios rather than fuzzy blur effects.
- **Editorial Typography:** High-contrast scale pairings bridge technical engineering data with modern editorial cadence.
- **Controlled Kinetic Motion:** Transitions mimic native 120Hz gesture physics—stiff springs, immediate visual confirmations, and zero decorative deceleration lag.

## Colors

The core palette is grounded in low-light architectural surfaces, deliberately anchored away from absolute `#000000` to preserve depth, fine structural borders, and physical texture. 

### Dark Canvas & Surfaces (Default)
- **Primary Canvas (`#111113`):** Deep Charcoal. The non-emissive floor for all views.
- **Elevated Surface (`#19191C`):** Graphite. Applied to interactive cards, structural pods, and floating toolbars.
- **Structural Border (`#2A2A2E`):** Graphite Line. 1px solid boundaries providing crisp physical separation.
- **Primary Text (`#F4F4F5`):** Cloud White. High-contrast editorial headlines and critical metrics.
- **Secondary Text (`#A1A1AA`):** Cool Gray. Body narrative, contextual summaries, and navigation labels.
- **Muted Text (`#71717A`):** Stone Gray. Metadata, code syntax keys, inactive states, and structural grid indices.
- **Primary Accent (`#A3E635`):** Electric Lime. Used with surgical restraint for primary call-to-actions, focused terminal outputs, and live system status indicators. Must never receive neon diffusion or heavy drop blurs.

### Light Mode Inversion (Document Surface)
- **Primary Canvas:** Soft Paper (`#F7F7F5`)
- **Elevated Surface:** Pure Surface (`#FFFFFF`)
- **Structural Border:** Subtle Stone (`#E4E4E7`)
- **Primary Text:** Pitch Ink (`#18181B`)
- **Secondary Text:** Deep Neutral (`#52525B`)
- **Muted Text:** Subdued Slate (`#A1A1AA`)
- **Primary Accent:** Olive Lime (`#65A30D`) for WCAG AAA compliance against light surfaces.

## Typography

The typographic system pairs the structural, geometric presence of Space Grotesk (delivering the precision and sharp form-factors aligned with Satoshi) with the developer-grade technical utility of JetBrains Mono.

### Type Roles & Pairing Guidelines
- **Display & Headings:** Rendered in tightly tracked Space Grotesk. Display sizes command attention through negative letter spacing and condensed line heights, echoing high-end technical monographs.
- **Monospace System Layer:** JetBrains Mono is strictly utilized for technical metadata, execution benchmarks, git commit tags, native modules, dates, and micro-labels. All numerical metrics and data tables must use tabular figures.
- **Body Text:** Space Grotesk regular weights maintain legibility at micro and macro scales, providing an uninterrupted bridge between architectural headers and technical data readouts.

## Layout & Spacing

Layouts follow an asymmetric 12-column grid system capped at a maximum width of `1440px`. The grid encourages intentional structural tension: large negative-space voids balance dense engineering diagrams and real-time app demonstrations.

### Responsive Breakpoints & Grid Rules
- **Desktop (1024px – 1440px):** 12-column asymmetrical layout. Outer margins are anchored at `4rem` (`64px`), with `2rem` (`32px`) gutters. Heavy featured cards span 7 or 8 columns, paired with 5 or 4-column contextual inspection trays to break standard symmetric grid monotony.
- **Tablet (768px – 1023px):** 8-column layout. Outer margins transition to `2.5rem` (`40px`), with `1.5rem` (`24px`) gutters. Stacked content flows with modular vertical rhythm.
- **Mobile (< 768px):** 4-column fluid layout with `1.25rem` (`20px`) outer safety margins and `1rem` (`16px`) gutters. Interactive elements compress into swipeable horizontally paged viewports.

### Vertical Rhythm
Component grouping strictly adheres to an 8px base rhythm. Layout sections maintain breathing room via `space-2xl` (`64px`) and `space-3xl` (`96px`) margins to let technical artifacts read as gallery installations.

## Elevation & Depth

Depth in this system is created structurally through razor-sharp surface contrasts and 1px borders rather than diffuse drop shadows.

### Elevation Levels
- **Level 0 (Canvas):** Pure `#111113`. Zero elevation, base drawing surface.
- **Level 1 (Cards & Modules):** Surface `#19191C` framed with a 1px solid `#2A2A2E` structural border. No shadow. The distinction is pure tonal contrast.
- **Level 2 (Hover & Active States):** Surface shifts to `#222226` with the border elevating to `#3F3F46`. A minimal, surgical ambient shadow is introduced: `box-shadow: 0 12px 32px -8px rgba(0, 0, 0, 0.6)`.
- **Level 3 (Modals, Overlays & Floating Bars):** Translucent backdrop using `#19191C` at 85% opacity with `backdrop-filter: blur(16px)` and a continuous 1px `#3F3F46` containment border.

### Focus & Accents
Active borders and focus outlines must never employ blurry glow effects. They should be expressed as clean, high-precision `1px` or `2px` solid strokes of `#A3E635`.

## Shapes

The geometry pairs generous exterior container radii with compact, disciplined controls to establish visual nesting balance.

- **Primary Feature Containers & Showcase Cards:** Radii range strictly from `24px` to `32px` (`rounded-xl` / custom tokens), creating expansive architectural viewports for project demos.
- **Buttons & Control Inputs:** Sized systematically between `12px` and `14px` corner radii. This avoids generic pill shapes while keeping interactive touch targets visually distinct from square structural data boxes.
- **Tags, Code Blocks & Terminal Chips:** Set to `6px` to `8px` (`rounded-md`), highlighting their functional, dense data-first purpose.

## Components

### Buttons
- **Primary Action:** Solid Electric Lime (`#A3E635`) fill with Deep Charcoal (`#111113`) text in Space Grotesk Medium. Padding: `12px 24px`. Corner radius: `12px`. Hover state: Invert or shift background to `#BEF264` with no drop shadow.
- **Secondary / Ghost:** Transparent background with 1px solid Graphite Line (`#2A2A2E`), Cloud White (`#F4F4F5`) text. Hover state: Surface fills to `#19191C`, border illuminates to `#A1A1AA`.
- **System Command (Micro):** JetBrains Mono label, `8px 14px` padding, `#19191C` background with subtle `#2A2A2E` border, displaying integrated keyboard shortcut hints.

### Chips & Badges
- **Architecture / Tech Tag:** `#19191C` background, 1px `#2A2A2E` border, JetBrains Mono font (`label-sm`), Stone Gray (`#71717A`) text.
- **Status Badge (Live Production):** Pill form, `#19191C` background, housing a 6px static dot in Electric Lime (`#A3E635`) alongside uppercase monospace status text (`label-sm`).

### Cards & Project Showcases
- Built using Graphite `#19191C` with `24px` to `32px` corner radii and a mandatory `1px` structural boundary of `#2A2A2E`.
- Padding inside cards is generous: `32px` to `40px` on desktop, `20px` to `24px` on mobile.
- Headers inside cards display project index counters (e.g., `// 01`) in JetBrains Mono (`label-md`) styled in Stone Gray (`#71717A`).

### Input Fields & Terminal Consoles
- **Input Fields:** `#111113` inset surface, 1px `#2A2A2E` border, `12px` radius. Active focus: crisp 1px stroke of Electric Lime (`#A3E635`) with zero glow. JetBrains Mono placeholder text in Stone Gray (`#71717A`).
- **Interactive Code / Architecture Inspector:** Embedded panels showing bridge performance, FPS benchmarks, or React Native fabric thread states. Dark background (`#0D0D0E`), border-top header tab strip with monospace metadata tags, and syntax-highlighted code blocks.

### Selection Controls
- **Checkboxes & Radio Buttons:** Custom `18px` squares/circles with `1px` solid `#3F3F46` border and Deep Charcoal fill. Active state snaps to `#A3E635` solid check indicator with instantaneous 100ms spring transitions.
